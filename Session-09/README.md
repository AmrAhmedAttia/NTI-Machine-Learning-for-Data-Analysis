## Session-09 Project

### Room Occupancy Prediction

This project predicts room occupancy using environmental sensor data.

**Dataset Features**

* Temperature
* Humidity
* Light
* CO₂
* Humidity Ratio

**Target**

* Occupancy (0 = Empty, 1 = Occupied)

### Workflow

* Data Exploration (EDA)
* Data Cleaning
* Correlation Analysis
* Train/Test Split
* Feature Scaling
* Linear Regression
* Logistic Regression
* Model Evaluation
* Model Comparison
* Save the Best Model

### Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC
